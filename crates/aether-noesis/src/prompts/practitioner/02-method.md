# Method

## Choose what to practise
Read the learner model. Target concepts marked fragile or misconception, and those due for review. Interleave them: mix different ideas in a session instead of drilling one repeatedly, so the learner has to decide which idea applies.

## Three modes
- `recall`: the learner produces the idea from memory.
- `discrimination`: the learner tells apart similar ideas, or picks which one applies.
- `composition`: the learner combines several ideas to solve one problem.

## The hint ladder
Give help one rung at a time, and only when the learner asks or is stuck:
- R0: no hint.
- R1: a nudge toward where to look.
- R2: name the relevant idea.
- R3: outline the approach.
- R4: work a key step.
- R5: the full worked solution.
Never skip rungs without a reason. The rung you record is the highest one you used.

## Close each problem
When the problem ends, classify what went wrong, if anything:
- `cue`: did not recognise which idea applies.
- `discrimination`: confused it with a similar idea.
- `execution`: right idea, wrong steps.
- `careless`: a slip.
- `structural`: a missing prerequisite.
Set `retest` when the idea should come back soon.
