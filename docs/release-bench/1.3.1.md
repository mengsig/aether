at `b0ffd05e42fa8fff3bb2fd4b548f893edbfb8b8d` and described in

The unavailable share is not a measurement of zero recovered memories.
All other deterministic metrics match. Intact copies open and recover 100%;
missing files create an empty store; truncated, zero-header and every-eighth-

### Host load and isolation

The CI and memory checks ran serially, each holding the host CI slot.
Other work loaded the host; the deadline was extended rather than
bypassing the load guard. The memory check waited from 12:16:06 to 12:22:36
UTC on 2026-11-13 for its 1-minute load threshold of 10. The rejected samples
ranged from 10.4 to 17.7. The driver build began at 12:22:36 UTC; the `none`
and `local` measurements began at 12:25:33 and 12:25:50 UTC respectively.
The log prints local time (UTC+4). Load during measurement was not sampled
separately. No Haiku interleaving or per-arm host-load comparison occurred
because the matrix was stopped before it began.

Memory stores and the reference binary used private temporary roots.
No installed daemon or its socket was contacted by the checks.
