What the per-trial records show:

- Haiku: 8 tasks differ, 4 each way, and every loss misses a single check
  of its task (or two: `query-6`, 10/12). Only on 1.2.1: `bucket-1`,
  `exporters-5`, `exporters-8`, `query-6`; only on 1.2.2: `query-3`,
  `query-7`, `ranges-4`, `workstreams-9`.
- Luna: 33 tasks differ, the usual churn of a tier passing about half the
  set. 1.2.2 loses most in `bucket`, `exporters` and `pricing` (3 each)
  and gains most in `slug` (4), `cron`, `diff` and `duration` (3 each).
- Changes between 1.2.1 and 1.2.2 that reach an agent: Claude models carry
  the 1M window and compact at 256K (Claude Code gets
  `CLAUDE_CODE_AUTO_COMPACT_WINDOW`, Codex `model_auto_compact_token_limit`
  at 272K), a tool call interrupted by a daemon restart says to block rather
  than poll, and an agent whose approval policy asks for external effects
  is now asked before a shell command reaches the network.
- Claude Code moved from 2.1.299 (the 1.2.1 bench) to 2.1.306; both arms
  used the same CLI, so the pairs are unaffected.
