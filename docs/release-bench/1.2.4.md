# Release bench 1.2.4: no decrease

**Verdict: no decrease.** Haiku is **+0.0 points** against 1.2.3 (one-sided
95% bounds -2.7 to +2.7, McNemar p = 1.000; old-only 2, new-only 2) at x0.85
cost. Luna is **+3.6 points** (-5.5 to +11.8, p = 0.608; old-only 15,
new-only 19) at x1.04 cost. Neither tier meets the release rule's decrease
test (p < 0.1 with the interval below zero), so no cell was repeated. Cost
per trial shows no increase beyond noise: Haiku x0.85 (x0.63 to x1.17), Luna
x1.04 (x0.91 to x1.21). The set is off target, so the run's verdict reads
INCONCLUSIVE; the gate itself passed on both tiers with no warning. No trial
had an infra error or a harness failure.

- Haiku: 4 tasks differ, and every one misses a single check of its task.
  Only on 1.2.3: `exporters-0` (1.2.4 5/6), `exporters-7` (4/5); only on
  1.2.4: `query-10` (1.2.3 11/12), `workstreams-7` (7/8). The cost ratio
  below 1 comes mostly from one 1.2.3 trial, `pricing-2`, which passed but
  ran to the 600 s timeout and cost $0.36, about 15% of its arm's total.
- Luna: the flips spread over the families in both directions and mostly
  miss one or two checks. `pricing` went 2 tasks to 1.2.3 and 6 to 1.2.4;
  `port` went the candidate's way (1.2.3 27%, 1.2.4 64%), `edgecase` the old
  binary's (1.2.3 52%, 1.2.4 38%). Every Luna trial completed and was priced;
  median times were 28 s (1.2.3) and 27 s (1.2.4).
- Changes between 1.2.3 and 1.2.4 that reach an agent: none. Only the TUI
  changed (the agents tree and the HTML viewer's screenshot budget), and no
  trial runs the TUI.
- Claude Code 2.1.309 and Codex 0.164.0 on both arms; r123 ran 2.1.306 and
  0.163.0, so the absolute pass rates are not comparable across the two runs.
- An earlier attempt at this release ran the same pair of binaries on Claude
  Code 2.1.308. One of its candidate Luna trials failed in that sandbox before
  the model ran (Codex could not open its state database) and was graded as
  a loss, so that run is not the record. It read Haiku +0.0 [-2.7, +2.7] and
  Luna -5.5 [-14.5, +2.7] (p = 0.405), which is not a decrease either.
