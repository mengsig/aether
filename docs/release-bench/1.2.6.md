# Release bench 1.2.6: no decrease

**Verdict: no decrease.** Haiku is **-1.8 points** against 1.2.5 (one-sided
95% bounds -5.5 to +1.8, McNemar p = 0.688; old-only 4, new-only 2) at x1.20
cost. Luna is **-0.9 points** (-9.1 to +7.3, p = 1.000; old-only 16,
new-only 15) at x0.94 cost. Neither tier meets the release rule's decrease
test (p < 0.1 with the interval below zero), so no cell was repeated. The
gate passed on both tiers; it warned on Haiku's cost point estimate (above
x1.15). The set is off target, so the run's verdict reads INCONCLUSIVE.

**Haiku's cost rise is one trial's model choice.** In `workstreams-5` the
candidate's Haiku root delegated its four children to
`claude-code/claude-sonnet-5-5`, where the old binary's root chose Haiku:
$0.421 against $0.031 for fewer tokens (609k against 709k). Without that
task Haiku is x1.02 (90% bootstrap x0.89 to x1.17), every other template
lies between x0.95 and x1.09, and the median paired ratio is x1.00. Nothing
the model sees changed between the two binaries, so no rerun was made.

- Haiku: 6 tasks differ. Only on 1.2.5: `cron-8`, `query-2`, `query-7`,
  `workstreams-9`; only on 1.2.6: `exporters-0`, `query-4`. In
  `workstreams-9` both roots delegated four Haiku children and ran the same
  six turns; the candidate's work failed one of 8 checks.
- Luna: the flips spread over the families in both directions (31 tasks);
  `port` went the candidate's way (64% against 45%), `docspec` the old
  binary's (24% against 33%). The old binary's `versions-5` trial failed
  after 4.0M tokens and could not be priced, so Luna's cost compares 109
  pairs.
- No trial had an infra error or a harness failure.
- The only change between 1.2.5 and 1.2.6 that reaches an agent is how
  Claude Code acknowledges messages steered into a running turn (#305 and
  this release's two follow-up fixes). No bench trial steered a message
  into a live turn: each Haiku arm consumed 5 inbox items, all in the
  delegation tasks and all at the start of a turn. The bench therefore
  checks that nothing else moved; the fix itself was checked live (see the
  1.2.6 pull request).
- Claude Code 2.1.309 and Codex 0.164.0 on both arms, as in r125.
- A first invocation stopped before any trial because the environment
  lacked `XDG_RUNTIME_DIR`; it recorded nothing and was removed.
