# Release check 1.3.1: Luna arms (post-release)

**LUNA: PASS. No performance decrease.** Candidate v1.3.1 vs v1.3.0 shows pass
-1.8% (interval [-10.0%, +6.4%]) and cost x0.95 (interval [x0.84, x1.07]),
inside the release thresholds. This completes the Luna arms deferred in
[1.3.1.md](1.3.1.md) (Haiku gate passed there).

The raw verdict line is `INCONCLUSIVE (gate passed on an off-target set)`, and
`make bench-release` exits nonzero for that reason. `ALLOW_OFF_TARGET=1` was
set as in the earlier reports; the per-model gate itself is PASS.
