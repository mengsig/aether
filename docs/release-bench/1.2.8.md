# Release bench 1.2.8: no decrease

**Verdict: no decrease.** Haiku is **+0.9 points** against 1.2.7 (one-sided
95% bounds -2.7 to +4.5, McNemar p = 1.000; old-only 3, new-only 4) at x0.84
cost. Luna is **-5.5 points** (-14.5 to +3.6, p = 0.392; old-only 20,
new-only 14) at x1.10 cost (x0.95 to x1.28). Neither tier meets the release
rule's decrease test (p < 0.1 with the interval below zero), so no cell was
repeated, and cost per trial did not rise markedly: Luna's interval holds
x1.00 and its arms differ by $0.056 over 110 trials. The gate passed on both
tiers; it warned on Luna's pass point estimate (below -5%). The set is off
target, so the run's verdict reads INCONCLUSIVE.

**Luna's point estimate is within the set's noise.** The A/A check of set v2
([release-bench-2026-10-18-aa-v2](../release-bench-2026-10-18-aa-v2.md)),
the same binary on both arms, measured Luna at -10.0 points (p = 0.099; 24
against 13). Here the flips run both ways inside the same templates
(`duration` 3 to 4, `pricing` 3 to 2, `bucket` 3 to 1, `exporters` 1 to 2),
and the check fraction moved -3.2 points (-7.0 to +0.4).
