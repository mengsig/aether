# Release bench 1.2.11: no decrease

**Verdict: no decrease.** Haiku is **+1.8 points** against 1.2.10 (one-sided
95% bounds -1.8 to +5.5, McNemar p = 0.688; old-only 2, new-only 4) at x1.03
cost (x0.96 to x1.09). Luna is **-5.5 points** (-12.7 to +1.8, p = 0.327;
old-only 16, new-only 10) at x0.89 cost (x0.77 to x1.03). Neither tier meets
the release rule's decrease test (p < 0.1 with the interval below zero), and
neither cost interval lies above x1.00, so no cell was repeated. The gate
passed on both tiers; it warned on Luna's pass point estimate (below -5%), as
it did at [1.2.8](1.2.8.md) with the same -5.5. The set is off target, so the
run's verdict reads INCONCLUSIVE.

**This is the first Luna check since 1.2.8.** Codex's quota was exhausted
for [1.2.10](1.2.10.md), and 1.2.9 had no per-release run, so Luna's old arm
here is 1.2.10, two releases after the last Luna measurement.

**Luna's point estimate is within the set's noise.** The A/A check of set v2
([release-bench-2026-10-18-aa-v2](../release-bench-2026-10-18-aa-v2.md)),
the same binary on both arms, measured Luna at -10.0 points (p = 0.099).
Here the flips run both ways inside the same templates (`cron` 2 to 3,
`duration` 3 to 1, `pricing` 2 to 3, `bucket` 1 to 1), and the check
fraction moved -1.5 points (-5.4 to +2.3). Two of the 16 old-only tasks are
model behaviour, both counted as failed trials. In `workstreams-5` the
candidate's Luna root delegated its four children to
`codex/gpt-6.1-terra` where 1.2.10's root kept them on Luna, as 1.2.10's
Haiku root chose Sonnet in `workstreams-7`; the spend guard stopped the
trial at $0.169 against its $0.15 allowance. In `pricing-6` Luna spent its
4,000,000-token budget in 80 tool calls over 257 s without a passing
answer. Without those two Luna is 49 against 53 (p = 0.541). Nothing that decides an agent's model
or its delegation changed between the two binaries.
