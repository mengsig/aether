# Release check 1.4.3: full bench vs v1.4.2

**RESULT: NO REGRESSION by the release gate (Haiku PASS, Luna PASS), with two cautions below.**

Raw command verdict: `INCONCLUSIVE (gate passed on an off-target set)`; the
command exits nonzero on this set by design, as in [1.3.1](1.3.1.md).
`ALLOW_OFF_TARGET=1` was set.

## Cautions

- **Haiku pass rate is lower on the candidate.** 102/110 (93%) against
  v1.4.2's 106/110 (96%): -3.6 points [-8.2, +0.0], McNemar 6 old-only /
  2 new-only, p = 0.289. This is inside the -5 point warning line and not
  significant, so the gate passes, but the data cannot exclude a loss of
  about 8 points. Three of the six old-only tasks are `exporters` (the
  `refactor` family: 75% old, 38% new, 8 tasks), so this family is worth
  a look. Native Haiku is at 94%,
  so the drift reference is flat.
- **Luna cost is higher on the candidate.** Cost ratio new/old x1.17
  [x0.99, x1.38], past the x1.15 warning line. The interval includes 1, so
  it is not significant and the gate passes, but a real rise of up to 38%
  is not excluded. One `luna/old` trial was unpriced. Luna pass rate is
  unchanged (-0.9 points [-10.0, +7.3], McNemar 17 / 16, p = 1.000).

- NEW: this branch's release build (`archon/bhe7da3j-...`, based on the
  1.4.3 version bump, head `a41a79868`), `aether 1.4.3`; OLD: published
  v1.4.2 Linux x86_64 musl archive, downloaded into a fresh temporary

  BUDGET=40 EXTRA=--run-id=rel-1-4-3`, inside the host CI slot. Set
  `bench/release-set/v2`, 110 tasks, sha256 `7f3166c96e35e2ad`; native CLIs
  claude 2.1.331, codex 0.172.0; one repeat; timeout 600s.
- 660 of 660 trials completed in one invocation (166.9 min wall), no
  resume, 0 infra errors, 0 harness failures, spend USD 9.67
  API-equivalent. Timeouts (600s, graded as recorded): `haiku/new`
  pricing-2; `luna/old` workstreams-7, workstreams-8 (and slug-10 at 407s).
