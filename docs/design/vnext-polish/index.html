This report shows each screen before this polish pass next to the same screen after it. Every "Before" image is the frontend at 2f55b3dc; every "After" image is this branch. Both sets were taken headless on the end-to-end stack (real daemons, a faux engine, temporary roots), so no real credentials or operator data appear.

vNext design polish: before and after

22 screens, 40 states. Each state is shown at desktop width in the light theme; each screen's first state is also shown at a narrow (390 px) width in the dark theme. Pages taller than 2400 px are cropped at the bottom. The capture spec is web/e2e/specs/capture/screens.spec.ts; it also takes desktop dark and narrow light.

Across every screen

  • Every route without a nav entry names itself in the shell header and the document title.
  • One page kit in @aether-ui/ui (page, page head, page title, lede, eyebrow, back link, card, card title, label, loading, visually hidden), built only from existing tokens.
  • Empty and error states inside a card shrink to a quiet line; full-page states keep the large pattern.
  • One entrance motion (ui-rise at --motion-base with --ease-standard); reduced motion zeroes it.
  • Card radii, label styles and breakpoints are the same on every screen.
